# YieldFlow ERP — серверная часть (API)

NestJS + PostgreSQL. Вход по логину и паролю (JWT), разделы «Птичники» и «Склад яйца», документация Swagger.

Документация API после запуска: `http://localhost:3000/api/docs`

## Технологии

| Что | Чем |
|---|---|
| Сервер | NestJS 12 (TypeScript), Express |
| База данных | PostgreSQL, TypeORM, миграции |
| Вход | JWT-токен, пароли хранятся как хеш bcrypt |
| Проверка данных | class-validator (DTO), глобальный ValidationPipe |
| Защита | Helmet, CORS по списку адресов, ограничение числа запросов (throttler) |
| Документация | Swagger (OpenAPI) |
| Тесты | Vitest + Supertest, настоящая PostgreSQL |

## Запуск на своём компьютере

Нужны Node.js 22+ и PostgreSQL (можно взять бесплатную базу на neon.tech и вставить её адрес в `DATABASE_URL`).

```bash
cd backend
npm install
cp .env.example .env     # затем заполните JWT_SECRET, ADMIN_PASSWORD и DATABASE_URL
npm run start:dev        # http://localhost:3000/api
```

При первом запуске сервер сам применит миграции, создаст администратора (из `ADMIN_LOGIN` / `ADMIN_PASSWORD`) и, если база пуста, заполнит её демо-данными.

## Команды

| Команда | Что делает |
|---|---|
| `npm run start:dev` | запуск с автоперезагрузкой |
| `npm run build` | сборка в папку `dist` |
| `npm run start:prod` | запуск собранного сервера |
| `npm test` | быстрые тесты без базы (сортировка яйца, проверка настроек) |
| `npm run test:e2e` | сквозные тесты с настоящей базой (см. ниже) |
| `npm run lint` | проверка кода |

### Сквозные тесты

Перед тестами содержимое базы **полностью удаляется**, поэтому нужна отдельная тестовая база, и слово `test` в её имени обязательно (иначе тесты не запустятся):

```bash
TEST_DATABASE_URL=postgres://postgres:postgres@localhost:5432/yieldflow_test npm run test:e2e
```

## Основные адреса API

Все адреса, кроме входа и `/health`, требуют заголовок `Authorization: Bearer <токен>`.

| Метод | Адрес | Что делает |
|---|---|---|
| POST | `/api/auth/login` | вход, возвращает токен (не более 5 попыток в минуту) |
| GET | `/api/auth/me` | текущий пользователь |
| GET | `/api/health` | сервер жив (без обращения к базе) |
| GET | `/api/health/db` | база отвечает |
| GET/POST | `/api/houses` | список / добавление птичников |
| GET/PATCH/DELETE | `/api/houses/:id` | один птичник |
| POST/GET | `/api/houses/:id/daily-reports` | внести суточный отчёт / история отчётов |
| POST | `/api/houses/:id/receive-flock` | принять выведенный молодняк |
| POST | `/api/houses/:id/remove-birds` | убрать птицу (например, на убой) |
| GET/POST | `/api/egg-warehouse/batches` | партии валового яйца / приёмка партии |
| POST | `/api/egg-warehouse/batches/:id/sort` | сортировка партии (транзакция) |
| GET | `/api/egg-warehouse/stocks` | остатки готового яйца по категориям |
| GET | `/api/egg-warehouse/summary` | итоги склада |
| POST | `/api/demo/reset` | вернуть демо-данные (только администратор) |

## Настройки (переменные окружения)

См. `.env.example`. Если обязательная настройка не задана или слишком слабая (секрет короче 32 символов, пароль короче 8), сервер не запустится и назовёт причину.

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | строка подключения к PostgreSQL |
| `JWT_SECRET` | секрет для подписи токенов, минимум 32 символа |
| `JWT_EXPIRES_IN_SECONDS` | срок действия входа (по умолчанию 8 часов) |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | первый администратор |
| `CORS_ORIGINS` | адреса сайтов, которым разрешён доступ (через запятую) |
| `SEED_DEMO_DATA` | заполнять ли пустую базу демо-данными |
| `PORT` | порт сервера (по умолчанию 3000) |

## Развёртывание

Сервер — на Render (бесплатный тариф), база — на Neon (бесплатный тариф). Описание сервиса лежит в `render.yaml` в корне репозитория. Бесплатный сервер засыпает после 15 минут без запросов и просыпается около минуты, поэтому страница входа заранее «будит» его запросом `/api/health`.
